# Oh My Pi Agent Implementation Plan

> **For agentic workers:** Implement this plan task-by-task using the host Agent's execution and delegation rules. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add native Oh My Pi task-agent support, including discovery, model selection, terminal execution, progress, cancellation and exact session continuation, plus general-agent ACP transport.

**Architecture:** Extend existing CLI registries, PTY sessions and headless/ACP runners rather than adding a second agent framework. Keep triage/reports and stranger work fail-closed until independently verified restricted execution exists. Use OMP's documented JSON events and ACP session identifiers rather than parsing presentation text.

**Tech Stack:** Python/FastAPI, SQLite, React/MUI, Node test runner/Puppeteer, installed omp 18.15.0.

**Spec:** User-approved integration description in the preceding conversation: native task-agent support first; restricted triage/report support excluded. Local `omp --help` confirms print, JSON, resume, model, async-wait and ACP flags; an isolated ACP initialize using the existing ACPClient succeeded without model calls.

## Global Constraints

- Work in C:/project/taskuary-omp; do not mutate the running real application's home or connections.
